# AI-ассистент — фронтенд

Интерфейс руководителя ООО «Фотопринт» на React, TypeScript и Vite. Все разделы используют FastAPI.

## Запуск

Из корня репозитория запустите сервер и базу по [основной инструкции](../README.md). Для локальной разработки подходит `LLM_PROVIDER=fake`. Из папки `frontend` установите зависимости и запустите Vite.

```bash
npm ci
cp .env.example .env.local
npm run dev
```

В PowerShell для копирования используйте `Copy-Item .env.example .env.local`. Откройте URL из вывода Vite. Запросы `/api` по умолчанию идут на `http://localhost:8000`. Для другого порта задайте `VITE_DEV_API_TARGET` в `.env.local` или окружении и перезапустите Vite.

Вход через `POST /auth/login` принимает `login` и `password`. На тестовом стенде `VITE_DEMO_PASSWORD` включает быстрый вход и переключение двух ролей из `GET /auth/demo-accounts`. Значение совпадает с `DEMO_PASSWORD` сервера и попадает в браузерную сборку. Для обычного входа оставьте `VITE_DEMO_PASSWORD` пустым.

## Сборка и контракт

- `npm run build` проверяет TypeScript и создаёт `dist/`.
- `npm run generate:api` обновляет `src/api/schema.d.ts` из `http://localhost:8000/openapi.json`.
- Docker-образ обслуживает `dist/` через nginx и проксирует `/api/` на `api:8000`. `VITE_API_BASE` задаётся при сборке.

Решения, поручения, публикация протокола и отправка писем выполняются через карточку действия. Правки отправляются с `revision`, подтверждение — с `revision` и `payload_hash` из актуальной карточки. Источники и права доступа проверяет сервер. Кнопка «Печать / PDF» открывает системную печать для брифинга, решения и опубликованного протокола.
